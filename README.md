# Homebrew tap for claude-pet

```bash
brew install r45635/tap/claude-pet
claude-pet setup
```

[claude-pet](https://github.com/r45635/claude-pet) is a tiny creature on your Mac that shows
what Claude Code is doing. `setup` wires it into Claude Code and starts it at login; the app
updates itself from then on. To remove it: `claude-pet uninstall`, then
`brew uninstall claude-pet`.
